The spice must flow

Arrakis Spice Labels

List your spices, pick a design, press print. Jar labels 60×30 mm, lid labels Ø27 mm, box labels 70×70 mm — laid out on A4.

Design

Print

In the print dialog choose A4, scale 100 % (not “fit to page”), margins none, and turn on background graphics.

Spices

One spice per line. Write Name / variant (e.g. Paprika / søt) for the small line under the name, and optionally Name / variant / origin. “box” prints a box label for the category, with a row per spice to write the grams on.
